## 🏛️ 三大独创排版与文稿编辑体系（核心技术护城河）

### 一、中式古籍专属 Markdown 标记语言 (Zhipu-Markup AST)
平台自主研发了面向中式古籍刊印的递归下降解析器与抽象语法树（AST），将现代 Markdown 语法与传世谱牒礼制完美融为一体：

- **古代礼法尊崇与抬头体系**：
  - `#` / `##` / `###` 三级标题根据空格自动计算缩进，严格支持明清谱例特有的**【平抬】、【单抬】、【双抬】、【三抬】**（每遇先祖名讳或皇封敕命，另起一栏顶格或超出栏外书写）；
  - **原地【挪抬】**：支持 `[[挪抬]]` / `[[挪抬N]]`，原地空出若干字位继续书写，不换栏亦表敬意。
- **三大传世注疏与夹注形态**：
  - **细高双行夹注 `##文字##`**：传统刻本最经典的双行小字注，在单行正文字位内精巧并排两列细高小注；
  - **紧凑方格夹注 `%%文字%%`**：正方形 2×2 点阵紧凑双列夹注；
  - **单列侧字小注 `$$文字$$`**：整字高、横向半宽的单列小字，精确附着于正文字位右侧，具宋元刻本古韵。
- **金石墨印与典章标记**：
  - `[[专:文字]]`：专名号，在先祖名讳、地名左侧生成通长竖线；
  - `[[书:文字]]`：书名号，字侧生成优雅波浪线；
  - `[[围:文字]]`：字外线框墨围（圈名考订）；
  - `<反白>文字</反白>` / `[[白:文字]]`：金石拓印风格的**墨底纸字阴刻反白效果**，用于碑文、堂号匾额；
  - `{红{朱砂文字}}` 等七色批注：精准还原传统朱墨套印古本，支持朱砂红（`#c0392b`）、松柏绿（`#0f766e`）等七色批点；
  - `@文字@` 原文锁定：繁简转换豁免标记，确保古籍特有避讳字、谱名不被机器自动化转错。

### 二、文内插图三维网格坐标定位与自由画板
- **三维网格精确定位 `![说明](url){x, y, z}`**：
  - 彻底打破传统排版软件“图片只能上下推移”的局限，以古籍半叶内框为基准坐标系，半栏格为单位；
  - `x, y` 确定在古籍版心内的几何起点，`z` 设定占格宽度，系统根据原图比例算术推导高度，**实现古籍插图与竖排文字的精准同叶绕排与嵌合**。
- **独占半叶自由画板排版**：
  - 支持多图独立半叶自由布局，在画布上支持相对坐标 `x, y, w, h, rot`（旋转）拖拽微调，所见即所得。
- **古籍行组插图排版**：
  - 自动支持同半叶多图横向并置、纵向顺排或空行另起半叶。

### 三、古式横带栏格表与字辈方格阵列
- **正统古籍栏格表（Ancient Grid Table）**：
  - 兼容标准 Markdown 表格语法（`| 表头 |` + `|---|` + `| 数据 |`）；
  - 自动编译为中式古籍全宽横带表格，支持 `{{table|表名}}` 挂载古式表名题签带，通栏贯穿版心三栏。
- **字辈活字方格阵列 (PoemGrid)**：
  - 专为五言、七言宗族派语诗打造，一字一格，右起竖排，如宋代活字印版般庄重威严。
- **通高栏界竖线 `---` (ColRule)**：
  - 独占行分隔线自动实现卷内换栏，并在栏间拉出通高贯通的传统墨色栏界竖线。
